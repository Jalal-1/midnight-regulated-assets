# RWA Token

**Use case:** issuing regulated real-world assets — working example: a
money-market fund share — with compliance built into the asset, while holdings
stay private on public rails.

Deliberately brief, and the brevity is the point: **same blocks, different
composition.**

- **Changes:** compliance checks, transfer restrictions, allowlists, disclosure policy
- **Unchanged:** custody, privacy machinery, issuer controls

Lifecycle demo + build-it, then the generalisation table: deposit / fund share /
bond / e-money — one row each, which blocks, what differs.
